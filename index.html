Unidad 1: Arquitectura de Cómputo

1.1 Módulos de Arquitectura

1.1.1 Arquitecturas Clásicas

Las arquitecturas clásicas establecieron los fundamentos de la computación moderna. El modelo Von Neumann utiliza un único bus para datos e instrucciones, mientras que Harvard usa buses separados. Estas arquitecturas dieron origen a los primeros computadores comerciales.

1.1.2 Arquitecturas Segmentadas

La segmentación o pipeline divide la ejecución de instrucciones en etapas secuenciales (fetch, decode, execute, etc.), permitiendo que múltiples instrucciones se procesen simultáneamente en diferentes fases.

1.1.3 Multiprocesamiento

Sistemas con múltiples procesadores que ejecutan tareas concurrentemente. Incluye arquitecturas SIMD (Single Instruction Multiple Data), MIMD (Multiple Instruction Multiple Data) y sistemas multicore.

1.2 Análisis de componentes

1.2.1 Arquitecturas

1.2.1.1 Unidad Central de Procesamiento

El CPU es el cerebro del computador, compuesto por unidad de control, ALU y registros. Procesadores modernos incorporan múltiples núcleos y cachés.

1.2.1.2 Unidad Aritmética Lógica

Componente que ejecuta operaciones matemáticas y lógicas. Su diseño determina el rendimiento del procesador en cálculos.

1.2.1.3 Registros

Pequeñas memorias de alta velocidad dentro del CPU. Tipos: propósito general, de instrucción, contador de programa y de estado.

1.2.1.4 Buses

Canales de comunicación que conectan componentes. Tipos: bus de datos, direcciones y control.

1.2.2 Memoria

1.2.2.1 Conceptos básicos

Jerarquía de memoria: registros, cache, RAM y almacenamiento secundario. Técnicas como paginación y segmentación para gestión eficiente.

1.2.2.2 Memoria principal

RAM almacena datos e instrucciones en uso. DRAM es común por costo, SRAM es más rápida pero cara. Tecnologías modernas: DDR4/DDR5.

1.2.2.3 Memoria cache

Memoria ultrarrápida (L1, L2, L3) que almacena datos frecuentes. Algoritmos LRU para gestión de contenido.

1.2.3 Manejo de entrada/salida

1.2.3.1 Módulos E/S

Interfaces que adaptan señales entre periféricos y sistema central. Controladores para USB, SATA, Ethernet.

1.2.3.2 E/S programada

Método donde CPU controla directamente transferencias, verificando estado constantemente (polling).

1.2.3.3 E/S con interrupciones

Dispositivos notifican al CPU cuando están listos mediante señales de interrupción.

1.2.3.4 DMA

Acceso directo a memoria permite transferencias sin involucrar al CPU.

1.2.3.5 Canales y procesadores E/S

Sistemas con procesadores dedicados para gestión de E/S, común en mainframes.

1.2.4 Buses

1.2.4.1 Tipos de buses

Buses del sistema, expansión, almacenamiento y periféricos. Características de ancho de banda y latencia.

1.2.4.2 Estructura de buses

Líneas de datos, direcciones y control. Arquitectura paralela vs serial.

1.2.4.3 Jerarquía de buses

Sistemas con múltiples buses interconectados (northbridge, southbridge) para optimización.

1.2.5 Interrupciones

Mecanismo que permite a dispositivos notificar eventos importantes. Pueden ser hardware (dispositivos) o software (llamadas al sistema).

Unidad 2: Estructura y funcionamiento del CPU

2.1 Organización del procesador

El CPU moderno está organizado en unidades funcionales: núcleos de procesamiento, unidad de gestión de memoria, controlador de buses y subsistemas de caché. La microarquitectura define cómo estas unidades interactúan.

2.2 Estructura de registros

2.2.1 Registros visibles para el usuario

Registros accesibles por programas de aplicación: datos (EAX, EBX), puntero (ESP, EBP), índice (ESI, EDI) en x86.

2.2.2 Registros de control y estados

Usados por el sistema operativo: registro de estado (EFLAGS) con flags de condición, registro CR0 para modos de operación.

2.2.3 Ejemplos CPU

Comparativa entre x86 (Intel/AMD) CISC, ARM RISC, y GPUs con miles de núcleos para paralelismo.

2.3 El ciclo de la instrucción

2.3.1 Ciclo Fetch-Decode-Execute

Fases: fetch (obtener instrucción), decode (interpretar), execute (realizar operación), write-back (guardar resultados).

2.3.2 Segmentación de instrucciones

Técnica que divide el ciclo en etapas independientes (5-20 etapas) permitiendo ejecución superescalar.

2.3.3 Conjunto de instrucciones

ISA define operaciones disponibles: aritméticas, lógicas, transferencia, control de flujo.

2.3.4 Métodos de direccionamiento

Inmediato (valor en instrucción), registro, directo, indirecto, indexado, relativo al puntero.

Unidad 3: Selección de componentes para ensamble

3.1 Chipset

3.1.1 Unidad central de procesamiento

Criterios: núcleos, frecuencia, caché, TDP, socket. Uso (oficina, gaming, servidor).

3.1.2 Controlador del bus

Gestiona comunicación entre CPU, memoria y periféricos. Northbridge (memoria/GPU), Southbridge (E/S).

3.1.3 Puertos de E/S

Selección según necesidades: USB 3.0/Type-C, Thunderbolt, HDMI/DisplayPort, Ethernet, audio.

3.1.4 Controlador de interrupciones

Gestiona prioridades de interrupciones. APIC modernos para sistemas multiprocesador.

3.1.5 Controlador DMA

Permite transferencias directas entre dispositivos y memoria. Considerar canales y compatibilidad.

3.1.6 Circuitos de temporización

Reloj del sistema y temporizadores programables para sincronización y multitarea.

3.1.7 Circuitos de control

Gestionan flujo de datos y señales: generadores de reloj, reset, gestión de energía.

3.1.8 Controlador de video

En gráficos integrados: resoluciones soportadas, aceleración hardware, memoria compartida.

3.2 Aplicaciones

3.2.1 Entrada/salida

Selección de periféricos: teclados/mouse, monitores (resolución, tasa de refresco), almacenamiento externo.

3.2.2 Almacenamiento

SSD vs HDD, interfaces (SATA, NVMe), capacidades. RAID para redundancia/rendimiento.

3.2.3 Fuentes de alimentación

Calcular requerimientos, eficiencia (80 Plus), modularidad, protección contra fluctuaciones.

3.3 Ambientes de servicio

3.3.1 Negocios

Confiabilidad, seguridad, soporte. All-in-ones para espacio, portátiles con duración de batería.

3.3.2 Industria

Resistente (polvo, humedad, vibraciones), rango térmico amplio, interfaces industriales (RS-485, CAN bus).

3.3.3 Comercio electrónico

Infraestructura escalable con balanceo de carga, alta disponibilidad, respaldo. Servidores con múltiples NICs.

Unidad 4: Procesamiento Paralelo

4.1 Aspectos básicos

Divide problemas en partes ejecutadas simultáneamente. Ventajas: mayor velocidad, capacidad para problemas complejos. Desafíos: sincronización, coherencia de datos.

4.2 Tipos de computación paralela

4.2.1 Clasificación

Según Flynn: SISD (secuencial), SIMD (vectorial), MISD, MIMD (multiprocesador). Granularidad: bits, instrucción, datos, tareas.

4.2.2 Arquitecturas secuenciales

Computadoras tradicionales con flujo único. Limitaciones físicas (ley de Moore) llevaron al paralelismo.

4.2.3 Organización de memoria

Memoria compartida (acceso común) vs distribuida (memoria local por procesador).

4.3 Sistemas de memoria compartida

4.3.1 Redes dinámicas

Interconexiones cambiantes: crossbar switches (alto rendimiento), buses multiplexados (económicos).

4.3.2 Redes conmutadas

Fat trees y multistage networks con múltiples rutas entre procesadores y memoria.

4.4 Sistemas de memoria distribuida

4.4.1 Redes estáticas

Conexiones fijas: mallas, toros, hipercubos, árboles. Cada topología con ventajas en latencia/ancho de banda.

4.5 Casos de estudio

Supercomputadoras: Summit (IBM), Sierra (NVIDIA), Fugaku (Fujitsu). Clusters Beowulf. GPUs con CUDA/OpenCL. Frameworks MPI y OpenMP.

Prácticas de Laboratorio

Prácticas de Arquitectura

Este espacio está diseñado para que agregues tus propias prácticas de laboratorio relacionadas con arquitectura de computadoras. Puedes incluir ejercicios prácticos sobre ensamblaje de computadoras, programación en bajo nivel, simulación de arquitecturas, o análisis de rendimiento.

Considera agregar imágenes de tus montajes experimentales, diagramas de circuitos, o capturas de pantalla de simulaciones. Este apartado es ideal para documentar proyectos prácticos que complementen los conocimientos teóricos adquiridos en el curso.

Espacio para prácticas

Ejemplos de Prácticas

Algunas ideas para prácticas que podrías incluir:

  • Ensamblaje de un computador personal desde componentes individuales
  • Programación en lenguaje ensamblador de un microcontrolador
  • Simulación de una arquitectura pipeline con diferentes configuraciones
  • Análisis de rendimiento comparando diferentes configuraciones de memoria
  • Implementación de algoritmos paralelos usando OpenMP o MPI
  • Diseño e implementación de una unidad lógica aritmética simple

Cada práctica debería incluir objetivos, materiales necesarios, procedimiento detallado, resultados obtenidos y conclusiones.
